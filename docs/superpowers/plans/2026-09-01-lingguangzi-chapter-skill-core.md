# Lingguangzi Chapter Skill Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and install a reusable Codex Skill that scans a chapter source folder, drafts and locks `chapter.json`, converts source content, builds a static chapter preview, and blocks publication until the required confirmations and QA checks pass.

**Architecture:** Keep the canonical Skill source in this repository under `skills/lingguangzi-chapter-site/`. Python command-line scripts provide deterministic inventory, hashing, document conversion, static HTML generation, and validation; `SKILL.md` orchestrates AI judgment for ambiguous file roles, OCR review, visual briefs, image generation, and user approval gates. Generated sites remain framework-free HTML/CSS/JavaScript suitable for GitHub Pages.

**Tech Stack:** Python 3 bundled runtime; Python stdlib `unittest`, `hashlib`, `json`, `pathlib`, `html`, `subprocess`; pypdf 6.10.0; python-docx 1.2.0; pdfplumber 0.11.9; Pillow 12.3.0; Poppler `pdftoppm` 26.05.0; static HTML/CSS/JavaScript.

**Spec:** `docs/superpowers/specs/2026-09-01-lingguangzi-chapter-skill-design.md`

## Global Constraints

- The source folder command is `N 章建立`; a user-authored `chapter.json` is not required before the first scan.
- `chapter.json` starts as `status: "draft"`; only an explicitly confirmed revision may become `status: "confirmed"`.
- Every supported source file must be referenced or listed in `excluded_files`.
- The manifest and generated page must support 多首詩歌 (`songs` array), multiple images, multiple audio items, and multiple videos without schema changes.
- `chapter.lock.json` is machine-managed and records relative path, byte size, modified time, SHA-256, role, and an aggregate inventory digest.
- Any source addition, deletion, or replacement invalidates confirmation and blocks building until the user confirms a revised manifest.
- Lyrics preserve source wording; scanned PDFs are flagged for OCR review rather than silently guessed.
- The original author cover is copied without modification.
- Main visuals are watercolor but must pass the visual-DNA and 最近六章 distinctiveness checks.
- The chapter 521 mobile type sizes and responsive behavior in the spec are minimum regression requirements.
- Local preview is the default terminal state. Git commit/push of chapter content requires the exact current-turn authorization `確認發布第 N 章`.
- The canonical Skill source is versioned in this repository; installation into `C:\Users\sbche\.codex\skills` happens only after validation and may require filesystem approval.

```python
from dataclasses import asdict, dataclass
import json
from pathlib import Path
from typing import Any


@dataclass(frozen=True)
class Issue:
    code: str
    severity: str
    message: str
    path: str | None = None

    def as_dict(self) -> dict[str, Any]:
        return asdict(self)


def read_json(path: Path) -> dict[str, Any]:
    return json.loads(path.read_text(encoding="utf-8"))


def write_json(path: Path, value: dict[str, Any]) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(value, ensure_ascii=False, indent=2) + "\n", encoding="utf-8")
```

```python
def role_candidates(relative_path: str) -> list[str]:
    folder, suffix = relative_path.split("/", 1)[0], Path(relative_path).suffix.lower()
    if folder == "原圖文" and suffix in {".png", ".jpg", ".jpeg"}:
        return ["original.cover"]
    if folder == "原圖文" and suffix == ".pdf":
        return ["original.pdf"]
    if folder == "詩歌創作" and suffix in {".mp3", ".m4a"}:
        return ["song.audio"]
    if folder == "詩歌創作" and suffix in {".docx", ".pdf", ".txt"}:
        return ["song.lyrics_source"]
    if folder.startswith("精煉篇"):
        return ["refined.image" if suffix in {".png", ".jpg", ".jpeg"} else
                "refined.document" if suffix == ".pdf" else
                "refined.audio" if suffix in {".mp3", ".m4a"} else
                "refined.video" if suffix == ".mp4" else "unknown"]
    return ["unknown"]
```
