# QA 与发布边界

响应式检查至少涵盖 320、375、390、430、768、1024、1280、1440 与 1920 px，并在手机与电脑确认：首次载入位于页面顶端、无水平溢出、三圆可见、锚点定位正确、Go Top 回到阅读选项、固定控制不遮住内容。正式验收另以 200% 缩放复查。

`N 章建立` 只产生清单草稿；`预览第 N 章` 只接受 confirmed manifest 与相符 lock。只有使用者在当次明确说出 `确认发布第 N 章`，才允许 commit、push 与 GitHub Pages 验证。较早回合或其他章的确认一律无效。

GoatCounter 未设定不阻挡本机预览，但阻挡正式发布验收。localhost 与 127.0.0.1 不得送出统计。
